# Fixtures

Sample Spokane OTA HDHomeRun data for development and tests.

## Source

- **`lineup.json`** and **`discover.json`** — captured from live HDHomeRun at `http://10.0.30.99` (HTTP 200). `DeviceAuth` in `discover.json` is redacted for the repo.
- **`xmltv-sample.xml`** — synthetic XMLTV fragment with SiliconDust channel ids (`US*.hdhomerun.com`) for unit tests.
